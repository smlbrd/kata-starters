# Ruby Kata Starter

A minimal, self-contained Ruby setup with a working example (`sum`)
and a passing test, ready for you to clear out and replace with your own kata.

**Prerequisites:** Ruby installed (`ruby --version` to check).

## Setup

```bash
bundle install
```

## Run

```bash
ruby main.rb
```

## Test

```bash
bundle exec rspec
```

## Files

- `main.rb` — entry point + `sum(a, b)` example method
- `main_spec.rb` — RSpec tests for `sum`
- `Gemfile` — dependencies (rspec)
