# JavaScript Kata Starter

A minimal, self-contained JavaScript setup with a working example (`sum`)
and a passing test, ready for you to clear out and replace with your own kata.

**Prerequisites:** Node.js installed (`node --version` to check).

## Setup

```bash
pnpm install
```

## Run

```bash
pnpm start
```

## Test

```bash
pnpm test
```

## Files

- `index.js` — entry point + `sum(a, b)` example function (exported for tests)
- `index.test.js` — Jest tests for `sum`
- `package.json` — dependencies (Jest) and scripts
